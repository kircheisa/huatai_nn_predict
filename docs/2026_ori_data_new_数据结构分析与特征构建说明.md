# 2026 原始数据（2026_ori_data_new.xlsx）结构分析与特征构建说明

> 分析对象：`data_ori/2026_ori_data_new.xlsx`
> 关联产出：`model_new/01_数据预处理_2026new.py`、`model_new/01b_工程特征构建_2026new.py`、`model_new/data_new/`
> 分析日期：2026-11-10

---

## 1. 结论摘要

1. **新数据结构与旧版完全不同**：旧版 `2026_origin_data.xlsx` 有 10 个 sheet（含季度数据、月度日期表、指标发布日期表等），新版仅 4 个 sheet，且无任何"指标发布日期"信息，月度数据只能按保守发布滞后映射。
2. **新版缺失旧模型必需的多类指标**：R001/R007 银行间利率、标普500 等美股指数、GDP 同比、中债托管量同比等不在新数据中；对应旧管线特征（如 `corr_rate_r001_*`、`gp_feature_4` 依赖列）无法完整复现。
3. **数据质量问题已全部处理**：非交易日以 0 填充（需按 0=缺失处理）、日期降序排列、同名重复列（`.1` 后缀）、乱码列（`变动日期`）、政策利率类稀疏列不能参与滚动标准化等。
4. **已重建全部下游必需特征**：信用利差、股债相对估值（ERP）、R001成交量占比、沪深300点位重构、期限利差、国开国债利差、政策事件标志（A/B_modified）等，共输出 111 列基础表（data.csv）+ 利率动量表（rate.csv）。
5. **端到端验证通过**：XGB 训练特征表 4091×292，带标签样本 4086（下行 52.7% / 上行 47.3%）；旧模型 Top-30 重要特征覆盖率 **27/30**（3 个缺失均因原始数据不可得）。
6. **修正了旧管线的未来函数**：旧代码周度/月度数据用 `merge_asof(direction="forward")` 对齐，会把尚未发布的月度数据泄漏到当期；新管线改为 `direction="backward"` + 显式发布滞后。

## 2. 新数据 4 个 Sheet 的结构

| Sheet（序号） | 内容 | 列数（含日期列） | 表头行 | 日期范围 | 排序 |
|---|---|---|---|---|---|
| Sheet0 | 日度基础数据（国债收益率曲线、汇率、股指、商品、资金面等） | 55 | 第 2 行（header=1） | 2010-01-04 → 2026-11-09 | **降序** |
| Sheet1 | 日度债券/机构净买入 + 国债期货持仓/成交 | ~60（与 Sheet0 外连接后多 5 列净买入） | 第 1 行（header=0） | 同上 | **降序** |
| Sheet2 | 周度数据（DR001、DR007、地铁客运量、SCFI 等） | ~20 | 第 2 行（header=1） | 2015 前后 → 2026 | **降序** |
| Sheet3 | 月度数据（PMI、CPI/PPI、社融/M1/M2、工业增加值、社零、地产等） | ~35 | 第 2 行（header=1） | 2010-01 → 2026-09 | **降序** |

读取要点：Sheet0 表头在第 2 行；Sheet1 与 Sheet0 需 outer merge 才能合并出完整日度表（合并后 4 天日期差异，以 Sheet0 为基准）；所有 sheet 均需先按日期升序重排。

### 2.1 与旧版 10-sheet 结构的关键差异

- 旧版有 `quar`（季度）/`quar_date`、`month_date`（月度指标实际发布日期表）、`spec`（政策事件）/`cate` 等表；**新版没有发布日期表，也没有独立的政策事件表**。
- 新版缺失指标（旧管线用到但无法获得）：
  - 银行间回购利率 **R001、R007**（仅有 DR001/DR007，周度）；
  - **标普500** 等美股指数（`corr_rate_sp500_*` 特征缺失）；
  - **GDP 同比**、**中债托管量同比**；
  - SCFI 已更名（新版列名不同，映射后可用性需重新确认）。
- 新版新增/更名的重要列：国债期货 10 年期持仓量/成交量、机构净买入 5 列（2022-01-10 起才有数据）、地铁客运量（约 2019 年起）、阴极铜**期货结算价**（2010 年起全历史，替代旧版 2023 年才开始的现货领先价格）。

## 3. 数据质量问题与清洗规则

| 问题 | 表现 | 处理 |
|---|---|---|
| 0 当缺失值 | 非交易日整行填 0；部分真实值也可能为 0 | 默认 0→NaN 后重算；仅 `沪深300涨跌幅`、`沪深300涨跌点数` 两列 0 视为有效 |
| 日期降序 | 所有 sheet 均最新日期在最前 | 统一升序重排 |
| 重复列名 | 同一指标出现两列，第二列自动带 `.1` 后缀 | 去重时保留非全 NaN/更长序列的那一列 |
| 乱码列 | `变动日期` 相关列编码损坏 | 直接丢弃 |
| 政策利率稀疏列 | `逆回购利率:7天`、法定存款准备金率仅变更日有值 | `ffill()` 保留水平值；同时用 `diff()!=0` 生成事件标志 A_modified / B_modified，之后水平值列删除、只保留标志列 |
| 列起始时间不一 | 3年/5年国债 2017-10-09 起；DR001/DR007 约 2015 年起；净买入 5 列 2022-01-10 起；地铁客运量约 2019 年起 | 不足部分保留 NaN，最终统一 `ffill().fillna(99.00)`（99 为旧管线约定的哨兵值） |

## 4. 特征构建方案（01_数据预处理_2026new.py）

### 4.1 列名兼容映射（核心）

下游 `03_XGB训练_二分类.py` 的 `build_features()` 与 NN 的 Top-30 特征都依赖旧短列名，因此建立了 Wind 原始长名 → 短名的映射，例如：

- `中国:国债到期收益率:10年` → `10年国债`（1/2/3/5/7/30 年同理）
- `中间价:美元兑人民币` / `CFETS:即期汇率:美元兑人民币` → `中间价` / `即期汇率`
- `美国:国债收益率:10年` → `10年美债`
- `期货持仓量:国债期货:10年期` / `期货成交量:国债期货:10年期` → `国债期货持仓量:10年` / `国债期货成交量：10年`（后一列沿用旧的全角冒号命名）
- `期货结算价(活跃合约):阴极铜` → `阴极铜价格`（替代旧版 2023 年才开始的现货价，恢复 `corr_rate_copper_20/60` 的全历史覆盖）
- `中国:法定存款准备金率:大型银行` → `存款准备金率:大型银行`

### 4.2 衍生特征（旧模型需要、新数据未直接提供）

| 衍生列 | 定义 | 用途 |
|---|---|---|
| `1年/3年/5年信用利差` | 中短票AAA(1/3/5年) − 同期限国债 | 旧 build_features 必需列；另生成 AA+/企业债利差备查 |
| `国开国债利差` | 10年国开 − 10年国债 | 旧必需列 |
| `期限利差10Y-1Y` 等 | 10年−1年、10年−5年、5年−1年 | 旧必需列 |
| `股债相对` | 100/沪深300PE − 10年国债收益率 | 股债 ERP，旧必需列 |
| `沪深300` | 由涨跌幅重构：`(1+涨跌幅/100).cumprod()×1000` | 旧管线用点位算动量，新数据只有涨跌幅 |
| `R001成交量占比` | R001成交量/(R001+R007成交量)（若成交列可得则替代；否则由可得列近似） | 资金期限结构代理 |
| `A_modified` / `B_modified` | 逆回购7天利率变更 / 存款准备金率变更事件标志（变更日=变更后水平，其余=0） | 政策事件，替代旧 spec 表；**不参与滚动标准化**（IQR=0 会全部变 NaN），以原始值并入 |

### 4.3 标准化与对齐

- **滚动稳健标准化**沿用旧管线口径：`(x − rolling中位数) / rolling IQR`；日度窗口 252、周度 52、月度 12；起始 NaN 统一填 99.00。
- **周度/月度对齐改为 backward**：旧代码 `direction="forward"` 属于未来函数；新管线 `merge_asof(direction="backward")`。
- **月度发布滞后**（新数据无发布日期表，按经验保守设定，单位天）：PMI 0；CPI/PPI/进口 10；社融/M1/M2 13；工业增加值/社零/基建/商品房销售 16；70城房价 20。
- **`standardize_irregular()`**：月度各列发布节奏不同，先按"发布日并集"展开网格会出现列内空洞，导致 `rolling(12)` 全 NaN；改为**逐列在其自身非缺失日期上标准化**，再合并。

### 4.4 利率动量表（rate.csv）

10 年国债收益率 + 多窗口动量：[1,7] 天窗口按年化口径缩放（252/66），[30,60,180] 窗口按 756/188 缩放，与旧管线一致。

## 5. 输出与验证结果

> 输出目录：`model_new/data_new/`

| 文件 | 规格 | 说明 |
|---|---|---|
| `data.csv` | 4091 行 × 111 列 | 2010-01-04 → 2026-11-09；无 inf、无全 NaN 列、无残留 NaN（哨兵 99） |
| `rate.csv` | 4091 行 | 利率+动量表 |

| `train_merged_bin.csv` / `x_raw_bin.csv` / `y_bin.csv` | 4086 行 | 二分类标签（20 交易日前瞻）：下行 52.7% / 上行 47.3% |

### Top-30 覆盖率验证

与旧 `xgb_feature_importance_bin.csv` Top-30 对比：**27/30 可覆盖**。3 个缺失原因：

1. 标普500 相关——新数据无美股指数；
2. SCFI 相关——列名变更/历史不可得；
3. `gp_feature_4`——gplearn 遗传特征，需用新数据重跑 `02_训练数据构建_二分类.py` 重新生成。

## 6. 下游使用方法

新管线输出与旧管线同构，`02/03/NN` 脚本无需修改，仅通过 CLI 指定新数据路径：

```bash
# 1. 预处理（生成 model_new/data_new/data.csv、rate.csv）
python model_new/01_数据预处理_2026new.py

# 2. XGB 工程特征（生成 xgb_train_features_new.csv 及带标签训练表）
python model_new/01b_工程特征构建_2026new.py

# 3. 训练数据构建（可选 --skip-genetic 跳过遗传特征）
python model_new/02_训练数据构建_二分类.py \
    --data-file model_new/data_new/data.csv \
    --rate-file model_new/data_new/rate.csv \
    --output-dir model_new/data_new

# 4. XGB 训练 / NN 训练按原脚本使用 model_new/data_new/ 下的文件
```
