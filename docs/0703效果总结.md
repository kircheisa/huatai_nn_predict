# 华泰证券国债收益率预测 — 0703 效果总结

## 一、项目概述

**目标**：预测10年期国债收益率未来5日的方向（二分类：下行=1 / 上行=0）

**核心模型**：XGBoost 二分类（binary:logistic）

**训练模式**：滚动窗口，W=180天，S=63天（季度步长），V=63天验证集

**数据范围**：2018-01-01 起，23个 fold，测试样本 1449 个

## 三、优化历程

### 3.1 三分类 → 二分类

- 三分类（±3BP阈值）在单边市场（如2024年强下行）中信噪比极低，±3BP容易将同方向运动切分为"偏多"和"震荡"，标签噪音大
- 转为二分类（只看方向，不设幅度阈值），消除标签噪音

### 3.2 滚动窗口优化

| 窗口 W | 训练天数(W-V) | 效果评价 |
|--------|---------------|----------|
| 90 | 27 | 训练集严重不足，跳过 |
| 120 | 57 | 训练集偏少，效果不稳定 |
| 150 | 87 | AUC最高但F1低 |
| **180** | **117** | **综合最优（Accuracy/F1/AUC平衡）** |
| 270 | 207 | 过多历史数据引入结构断裂噪音 |
| 360 | 297 | 同上，2022年后风格转变被旧数据污染 |

**结论**：W=180 综合最优，短窗口训练不足，长窗口受2022年后结构性断裂影响。

### 3.3 调参（4阶段贪心搜索）

4阶段按优先级逐维测试，每阶段选最优后传递到下一阶段：

| 阶段 | 参数 | 测试范围 | 最优值 |
|------|------|----------|--------|
| 1 | step | 42/63/84 | 63 |
| 2 | max_depth | 2/3/4/5 | 3 |
| 3 | learning_rate | 0.05/0.1/0.15/0.2 | 0.1 |
| 4 | min_child_weight | 1/3/5/8/10 | 8.0 |
| 5 | reg_alpha | 0/0.5/1/2/5 | 1.0 |

**核心规律**：小训练集(117天) + 高维特征(225维) → 越强正则化越好（mcw=8, ra=1.0）

## 七、核心结论与瓶颈

1. **模型整体仅略优于随机**：AUC=0.5351，Accuracy=0.5604 vs 基线0.5673
2. **二分类相比三分类有改善**：消除了±3BP标签噪音，但方向预测本身信噪比仍然低
3. **特征冗余严重**：225个特征中49个完全无效（21.8%），出现率>30%的仅7个
4. **rsi_24等高重要性特征不稳定**：单次importance高但跨fold一致性差，容易过拟合
5. **小窗口+高维特征的组合需要强正则化**：mcw=8, ra=1.0 远大于默认值
6. **2022年后市场风格转变**：中美利差倒挂、利率中枢下移，历史数据预测价值有限
7. **多数fold的best_iter极低**：8/23个fold的best_iter=0或1，模型倾向退化为只预测多数类

## 八、下一步优化方向

### 8.1 短期可实施（基于现有框架）

1. **删除49个无效特征**：225→176，减少噪音维度
2. **重点优化出现率>30%的核心特征**：
   - `rate_dollar_gap`：增加不同窗口的变体（30/90/120日偏离）
   - 信用利差变化：增加1年信用利差的变体
   - AR(1)系数：增加更短窗口（5日）
3. **将技术面哑变量改为连续值**：
   - `consec_up_days` → 改为 net_streak 的连续值形式
   - `bb_break_upper/lower_20` → 改为 bb_pctb_20 的连续偏离度
4. **调整 early_stopping**：best_iter=0 的 fold 过多，可能需要调整验证集策略

### 8.2 中期方向

5. **特征选择**：仅保留出现率>15%的~100个特征，降低维度
6. **集成学习**：用不同窗口/参数的多个模型投票，降低单模型方差
7. **样本权重实验**：对近3年样本加权，缓解2022年后结构性断裂

### 8.3 长期方向

8. **切换到神经网络架构**：BiGRU + Inception + Attention 序列模型
   - 优势：能直接处理时序依赖，无需手工构建lag/rolling特征
   - 适合：利用更长的输入序列（如120天）捕捉长程依赖
9. **强化学习/在线学习**：自适应权重更新，跟踪市场风格转变
