# XGBoost 模型优化与诊断分析

## 一、背景

基于 [43_3_华泰证券债券预测_XGB训练.py](file:///e:/datafun/大模型/43_华泰证券债券预测预处理/43_华泰证券预处理/43_3_华泰证券债券预测_XGB训练.py) 构建了 XGBoost 三分类模型，预测 10 年期国债收益率未来 5 个交易日的方向（偏多/震荡/偏空）。

经多轮迭代后，模型 Accuracy 始终低于多数类基线，Macro F1 在 0.32~0.39 区间徘徊。本文档系统记录诊断过程、已实施的优化及根本原因分析。

## 三、已实施的优化

### 3.1 优化清单与实测效果

| 优化项 | 实施方式 | 实测结论 |
|--------|---------|---------|
| 增加利差/汇率衍生特征 | 信用利差变化量、美元动量、汇率衍生、利率-美元协同 | 正面，18个新特征 |
| 增加股债相对回报率衍生 | `_chg_5d/_chg_20d/_ma_5/_ma_20/_deviation_20` | 正面，多个进入 Top 15 |
| 增加加杠杆情绪衍生 | R001/R007成交量动量、隔夜回购占比变化 | 正面，2类F1提升22% |
| 增加利率相对强度特征 | `rate_zscore_60`、`rate_percentile_60`、`rate_chg_5d_zscore` | 正面 |
| 去重遗传特征 | gp_feature_5/6/7(与2重复)、9/10(与8重复) 移除，10→5 | 中性，降噪但指标持平 |
| 滚动窗口训练 | 756天窗口每季度重训，取代固定切分 | 正面，Macro F1 +16% |
| 缩短训练集 | 从2010改为2018起，过滤1868条旧样本 | 正面，适配新市场环境 |
| 时间衰减样本权重 | 指数衰减(decay_rate=0.998/0.999) | **负面，已移除** |
| 超参调优 | depth 3→4, 正则放宽 | **负面，已回退** |

### 3.2 时间衰减权重为何失败

滚动窗口本身已包含"近因效应"——每次只用最近3年数据。在此基础上叠加样本权重衰减，会使窗口末端（最近的）样本权重过高，导致模型对近期数据过拟合，泛化性反而下降。实测 Accuracy 从 0.49 暴跌至 0.44。

### 3.3 超参调优为何失败

`max_depth=4` 配合更宽松的正则（reg_alpha 0.5→0.3, reg_lambda 2.0→1.0, gamma 0.1→0.05），导致 `momentum_30_robust_scaled` 单一特征占比飙升至 24%，模型严重过拟合。回退到 depth=3 + 原始正则后恢复正常。

## 四、根本原因分析

### 4.1 市场环境结构性转变（Regime Change）

国债收益率中枢在 2022 年后发生系统性下移：

| 阶段 | 均值 | 范围 |
|------|------|------|
| 训练集 (2005-2019) | 3.57% | [2.64, 4.72] |
| 验证集 (2019-2021) | 3.08% | [2.48, 3.43] |
| 测试集 (2021-2025) | **2.59%** | [1.60, 3.15] |

2024 年均值 2.22%、2025 年降至 1.67%，这些水平在训练集中从未出现。2022 年后中美利差倒挂、货币环境切换，模型在旧数据上学到的特征-标签关系部分失效。

### 4.2 标签定义与单边趋势冲突（核心问题）

#### 数据证据：2024 年 5 日变化分布

| 三分类标签 | 数量 | 占比 | 实际方向 |
|-----------|------|------|---------|
| 偏多（下行≥3BP） | 91 | 34.0% | 下行 |
| 震荡（±3BP内） | 136 | **50.7%** | **其中58%是小幅下行** |
| 偏空（上行≥3BP） | 41 | 15.3% | 上行 |

```
真实方向分布：  下行 170 (63.4%)  vs  上行 98 (36.6%)
标签告诉模型：  偏多 91 | 震荡 136 | 偏空 41
```

**震荡类内部有 79 个是 -3~0BP 的小幅下行**。这意味着同样在下行，有些被标记为"偏多"，有些被标记为"震荡"——区分标准仅是幅度是否超过 3BP。对模型而言，这两类样本的特征几乎一致但标签不同，构成**噪音标签**。

#### 震荡类内部构成

| 子类 | 数量 | 占震荡类比 |
|------|------|-----------|
| 小幅下行 (-3~0BP) | 79 | 58.1% |
| 小幅上行 (0~+3BP) | 57 | 41.9% |
| 均值 | -0.32BP | — |

#### 各年趋势对比

| 年份 | 5日均值 | 下行占比 | 市场环境 |
|------|---------|---------|---------|
| 2021 | -0.83BP | 55.8% | 温和下行 |
| 2022 | -0.07BP | 50.6% | 震荡 |
| 2023 | -0.49BP | 61.1% | 下行 |
| **2024** | **-1.98BP** | **69.5%** | **强下行** |
| 2025 | +3.24BP | 22.9% | 反弹上行 |

### 4.3 三分类任务信噪比过低

模型实际上被要求预测"下行幅度是否超过 3BP"，而非"方向"。5 日内 1~3BP 的波动很大程度上是随机的，超阈值与否更多由噪音决定。

- 全预测"偏多"：准确率仅 34%（因为 50% 被归为震荡）
- 全预测"震荡"：准确率 50.7%（当前多数类基线）
- 二分类下全预测"下行"：准确率 63.4%

## 五、建议的改进方向

### 5.1 改二分类（优先级 P0）

将三分类改为二分类：只预测方向（下行/上行），剔除"震荡"标签或将其按方向归入。

```python
# 方案A：剔除震荡，只训练方向明确的样本
def gen_label(value):
    if value < -0.01: return 0   # 下行（偏多）
    if value > 0.01:  return 1   # 上行（偏空）
    return np.nan                 # 小幅波动不参与训练

# 方案B：全部保留，按方向二分
def gen_label(value):
    return 0 if value < 0 else 1  # 0=下行, 1=上行
```

**预期效果**：
- 信号更干净，方向是真实信息，幅度是否超阈值更多是噪音
- 2024 年二分类基线为 63.4%（下行），模型若能超越此基线即有实用价值
- 类别平衡度更好，减少模型偏向预测多数类的问题

### 5.2 调整三分类阈值（优先级 P1）

当前 ±3BP 阈值与模型预测文档（`模型预测.md`）中定义的 ±5BP 不一致。建议：

```text
类别 0：y_future_5d <= -5BP    -> 偏多
类别 1：-5BP < y_future_5d < 5BP -> 震荡
类别 2：y_future_5d >= 5BP     -> 偏空
```

更宽的阈值能减少噪音标签，让三类边界更清晰。

### 5.3 预测窗口延长（优先级 P2）

5 日窗口的信噪比过低。延长至 10 日或 20 日可平滑短期噪音：

| 窗口 | 优势 | 劣势 |
|------|------|------|
| 5 日 | 反应快 | 噪音大，信噪比低 |
| 10 日 | 中等 | 中等 |
| 20 日 | 趋势清晰 | 反应慢 |

## 七、结论

经过多轮特征工程和超参调优，模型在三分类任务上的表现已接近瓶颈。根本原因不在特征或模型，而在**任务定义本身**：

1. ±3BP 阈值在单边趋势市场中制造了大量噪音标签
2. 三分类要求模型预测"幅度是否超阈值"，而非"方向"，信噪比过低
3. 2022 年后的市场环境结构性转变放大了上述问题

**下一步应优先改二分类**，将任务从"幅度分类"回归到"方向预测"，这是突破当前瓶颈的最有效路径。
